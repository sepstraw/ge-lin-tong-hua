# 十二个兄弟

从前有一位国王和王后，他们非常和睦，有十二个孩子，可是，他们全都是男孩。

有一天，国王对他的妻子说：“如果你生的第十三个孩子是女孩的话，那么这十二个男孩应该死去，这样她的财产就多了，这个国家也就归她一人所有了。”

国王还让人做了十二具棺材，棺材里面都装满了刨花，并在每具棺材中放了一个小枕头，然后让人把它们统统锁在一间小屋子里，把钥匙交给王后，同时规定她不准对任何人说起这件事。

可是，从这天起，这当母亲的整天坐着，忧心忡忡，因此，那个和她寸步不离、她根据《圣经》而称他“便雅悯”的最小的儿子就问她道：“亲爱的母亲，你为什么这样愁眉苦脸？”

“乖孩子，”她回答说，“这件事我不能告诉你。”

可是他老缠住她，不让她安宁，直到她起身去打开那间小屋子，指给他看那十二具装满刨花的棺材。

这时，她说道：“我亲爱的便雅悯，这些棺材是你父亲让人为你和十一个哥哥做的，因为我再生一个是女孩的话，你们大家都要被杀死，装在这里面。”

说到这儿，母亲哭了起来；儿子劝说道：“别哭了，亲爱的母亲，我们一定要救自己，要离开这里。”

于是母亲说：“你和你那十一个哥哥到外面森林里去，始终要有一个人呆在一棵容易看到远处的最高的树上站岗，注意这儿宫殿里的塔楼。如果我生的是一个男孩，那么我就会插一面白旗，然后你们可以回来；如果我生的是一个女孩，那么我就要插一面红旗，那么你们就逃走，越快越好，让仁慈的上帝保护你们吧。每天晚上我都要起来为你们祈祷；在冬天，你们可以生火取暖；在夏天，你们别到烈日中去挨晒。”

母亲为她的儿子们一一祝了福以后，他们就到外面的森林里去了。他们一个接着一个地放哨，坐在那棵最高的橡树上朝塔楼瞭望。

十一天过去了，当轮到便雅悯时，他忽然看到一面旗子升了起来，可是这旗子并不是白色的，而是一面血红的旗子，这意味着他们全都要被处死。

弟兄们听说这事以后，都非常气愤，纷纷说：“为了一个女孩，我们就该去死，这太冤枉了！我们发誓，一定要报仇：无论在哪里遇到女孩子，我们都要让她流血。”

就这样，他们往森林深处逃去。他们来到森林中最阴暗的地方，找到了一所糟糕透顶、里面一无所有的小房子。这时，大家都说：“我们要在这里住下，便雅悯，你年纪最小，身体也最弱，你就留在家里料理家务吧，我们其余的人都要出去找吃的。”

于是，他们在森林里穿梭地来往，打野兔、狍子、鸟儿和野鸽子以及所有可以吃的东西。他们把捕捉来的东西交给便雅悯，便雅悯给他们烧好，他们就是用这些食物充饥，填饱肚子。

他们在这小屋子里一起生活了十年，这些时间对他们来说并不长。

这时候，他们的母亲，王后生的那个女儿已经长大，她心地善良，容貌俊秀，额头上长着一颗金星。

有一天，这是一个洗衣日，她发现衣服中有十二件衬衣，于是就问她的母亲道：“这十二件衬衣是谁的？是父亲的话，显然都太小了。”

这时，母亲心情沉重地回答说：“乖孩子，这些衣服是你十二个哥哥的。”

“那么我十二个哥哥现在在哪里呢？”姑娘问道，“我怎么从来没有听说过他们？”

母亲回答说：“他们现在在什么地方，这只有上帝知道。他们在很远的地方四处漂流。”

说到这里，母亲便领着女儿来到那所小屋前，打开屋门，把装有刨花和小枕头的十二具棺材指给她看。“这些棺材，”母亲说道，“是为你的哥哥们定做的，可是在你出生以前，他们都偷偷地逃走了。”接着，她把一切都告诉了女儿。

公主听完后说道：“亲爱的母亲，别哭了，我一定要去找我的哥哥们。”

就这样，姑娘带着十二件衬衣出发了。她一直朝大森林深处走去，走了整整一天，将近傍晚的时候，她来到了那所糟糕透顶的小房子前。她走进小房子，看到里面有一个男孩，男孩见有人进来就问道：“你从什么地方来，想上哪里去？”

姑娘这样漂亮，又穿着华丽的衣服，额头上还长着一颗星星，这使男孩感到很惊奇。

这时，姑娘回答说：“我是一个国王的女儿，出来找我那十二个哥哥，我要走遍天涯海角，直到找到他们为止。”

接着，她还把他们那十二件衬衣拿出来给他看。这时，便雅悯才发现，这原来是他的妹妹，于是说道：“我是便雅悯，是你最小的哥哥。”

公主高兴得哭了起来，便雅悯也哭了，他们非常热烈地亲吻拥抱。然后他说道：“亲爱的妹妹，有一件事要告诉你：我们曾经说定，无论遇到哪一个姑娘，我们都要她死，因为是一个姑娘迫使我们离开我们的王国的。”

姑娘说：“如果我死了，能解救我的十二个哥哥，那么我非常愿意死。”

“不。”他回答说，“你不能死，你坐到那只大木桶底下去，等十一个哥哥回来后，我一定要说服他们同意。”

姑娘照他说的做了；天黑的时候，十一个哥哥打猎回来了，他们准备吃饭，坐到桌旁。接着，他们一边吃饭一边问道：“有什么新鲜事吗？”

便雅悯说：“你们不知道吗？”

“不知道，”他们回答说。

他接着说：“你们在森林里，我呆在家里，可知道的事情却比你们多。”

“哦，那么快给我们说说，”他们叫道。

便雅悯说：“那么你们答不答应我：我们遇到第一位姑娘时，不要再杀害她了？”

“好吧，”他们异口同声叫道，“就饶了她吧，你快说给我们听听。”

这时便雅悯说道：“我们的妹妹来了，”说着他便揭开了木桶。公主走了出来，她穿着一身华丽的衣服，额头上长着一颗金灿灿的星星，那么美丽，那么温柔和纯洁；大家一见高兴极了，搂着她的脖子，又是亲，又是抱，非常喜欢她。

从此以后，她就留在家里，帮助便雅悯料理家务。十一个哥哥仍然到树林里去捉野兔、狍子、鸟儿和野鸽子，提供吃的，妹妹和便雅悯两人负责烧煮，准备大家的饭。妹妹拾来柴禾烧火，采摘野菜当蔬菜，把锅子炖到火上，往往等十一个哥哥一回来，饭菜也就烧好了；她甚至还很会料理家务，床铺铺得干干净净，有条有理，哥哥们总是非常满意，同她也非常和睦。

一段时期内，兄妹俩在家里尽做美味可口的饭菜，大家聚在一起，坐在一块儿，又吃又喝非常快乐。

在他们这所简陋的房子边有一个小园子，里边长着十二朵百合花，这百合花有人称它是“大学生”；公主想用它们来给哥哥们助兴，于是她摘了那十二朵花，想在吃饭时送给他们每人一朵。

可是，她一摘下那些花，刹那间十二个哥哥变成了十二只乌鸦，朝树上飞去了，随后那所小房子连同小园子也消失了。这下，只有可怜的公主孤单单一人呆在荒凉的森林里，她四下张望，看到她身旁出现了一位老太太，这时，老太太对她说：“孩子，你刚才干什么了？为什么要摘那十二朵百合花？它们就是你的哥哥，现在他们要永远变成乌鸦了。”

姑娘哭着说道：“难道就没有什么办法解救他们了吗？”

“不，”老太太说，“除了一个办法外，整个世界就没有其他办法了，不过这个办法非常难，恐怕你是救不了他们的，因为你要保持七年的沉默，不能说话，不能笑，哪怕是一句话，即使是离七年还差一个小时，否则一切都将是白费力气，你的哥哥们都要因为那一句话而死掉。”

这时，姑娘暗自下决心道：“为了救我的那些哥哥，我一定记住。”

她走了，找到一棵很高的树，坐在上面纺起纱来，从此她不说也不笑了。

这当儿发生了一件事：有一天，一位国王来到森林里打猎，他有一条灵狗，这狗跑到姑娘坐着的那棵树下，围着树蹦了起来，一边还朝树上狂叫。这时，国王走了过来，看到了这位额头上长着金星的美丽公主，对她的美貌惊叹不已，不由得朝她喊了起来，问她是不是愿意做他的妻子。

她没有回答，只是微微点了点头。于是，国王亲自爬到树上，把她抱下来，放到马上，然后带她回去了。

婚礼办得非常隆重，热火朝天，可是新娘不说也不笑。

他们在一起相亲相爱地生活了几年，这时国王的继母，一个凶恶的妇人开始说年轻的王后的坏话了，她对国王说：“她是一个粗野的要饭的姑娘，你把她带回家，谁知道她暗地里会干出什么恶作剧来。如果她是个哑巴，不会说话，那么笑一笑总该会吧，不笑的人，心里一定有鬼。”

国王起初还不肯相信，可是老太太一直这样说她的坏话，指责她许多不是，后来国王终于让她说服了，处王后以死刑。

于是，院子里点起了一堆火，王后将被放在火里烧死。国王站在楼上的窗子前，眼泪汪汪地注视着，因为他仍然非常爱她。

当她被绑在柱子上，大火已经将它红通通的火舌舔到她的衣服时，正好是第七个年头将逝去的最后一刻。这时，只听见天空中传来一阵哗啦啦的声响，十二只乌鸦飞翔而来，降落到地上；它们刚一着地，立刻成了她那十二个哥哥，是她拯救了他们。

十二个哥哥同心协力扑打火焰，不一会儿就把火扑灭，救出了他们可爱的妹妹，他们亲吻她，拥抱她。

这时候，她才张开了她的嘴巴，可以说话了，她告诉国王她为什么装成哑巴，从来不笑。

当国王听说她是清白无辜的，感到非常高兴，从此以后他们和睦地在一起生活，白头到老。那个可恶的继母则受到了判决，他们把她放在圆桶里，桶里注满滚烫的油和毒蛇，就这样，她罪有应得地死去了。

（裴胜利译）
